# ArcPilot

ArcPilot is an original AI-style crypto copilot built for Arc Testnet.

It is inspired by the conversational crypto UX pattern used by products like HeyElsa, but it does not copy HeyElsa branding, text, layout, logo, or assets.

ArcPilot lets users:

- Connect an injected wallet such as MetaMask, Rabby, or Coinbase Wallet.
- Add or switch to Arc Testnet.
- Read Arc USDC balance through the Arc USDC ERC-20 interface.
- Send USDC on Arc Testnet only after user wallet confirmation.
- Type natural-language crypto commands.
- Preview planned modules for swap, bridge, yield, and risk review.
